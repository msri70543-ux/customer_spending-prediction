# **CUSTOMER SPENDING PREDICTION SYSTEM**



## **Problem Statement**:



Businesses often find it difficult to predict how much a customer is likely to spend. This project aims to predict customer spending based on factors such as age, income, and previous spending behavior using Machine Learning.



### **Objective:**



To develop a Machine Learning model that can predict the expected spending amount of a customer using historical customer data.



AI/ML Type:

Machine Learning



Learning Type:

Supervised Learning



Problem Type:

Regression



Algorithm:

Linear Regression



Input Features:

1\. Age

2\. Income

3\. Previous Spending



### **Output:**

Predicted Customer Spending Amount
